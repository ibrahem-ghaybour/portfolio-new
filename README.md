# Ibrahim Marwan Ghaybour — Portfolio

Personal front-end portfolio built with Nuxt 4, Vue 3, TypeScript, Tailwind CSS, shadcn-vue, and GSAP.

## Setup

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run preview` — preview production build
- `npm run generate` — static generation

## Content

All portfolio content lives in `app/data/portfolio.ts` with types in `app/types/portfolio.ts`. Update that file to change personal info, skills, experience, and projects without touching UI components.
